#Welcome to Read ME file. 

Problem statemet:
Smallholder farmers make season-defining decisions with almost zero predictive information. A late-detected disease outbreak can wipe an entire harvest. The challenge is turning sparse, satellite-sourced, regional data into something reliable enough for a farmer to actually bet a season on.

How our project closes the gap:
two targets:

Regression: Predict expected crop yield (tonnes per hectare)
Classification: Flag disease-outbreak risk

Plus unsupervised segmentation of fields into agro-climatic zones, all deployed as a low-bandwidth-friendly mobile advisory endpoint.
